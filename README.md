# 土壤滴灌控制 v3

- 乾燥值：800；感測值越低越濕。
- 建議控制範圍：100~200。
- 不同距離約需不同滴數到約150：
  - 距離0：約2滴
  - 距離1：約3滴
  - 距離2：約4滴
  - 距離3：約5滴
  - 距離4：約6滴
- 水分每1秒擴散1格。
- 蒸發每4秒減少0.12滴等效含水量，慢於擴散。
- 超過200表示太乾，低於100表示太濕。

MakeCode Extension 自訂積木本身不能在工作區直接展開成內部積木。
因此附 `auto-example.ts`，可切回 Blocks 直接查看自動控制的 if / else / forever 邏輯。
